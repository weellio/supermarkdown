What it understands

  
GitHub-style Markdown: tables, task lists, strikethrough, footnotes, ==highlights==,
  callouts (> [!NOTE], [!TIP], [!WARNING]…), front matter, code highlighting for 190+ languages{{LAZY_HELP}}.
  Raw HTML is allowed but cleaned, so scripts in a document can never run.
